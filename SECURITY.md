# Security policy
Report suspected vulnerabilities privately to the repository owner (GitHub: supachai-j) — do not open a public issue and do not paste secrets or customer data. Include version/commit, steps, impact. Acknowledgement target: 3 working days. Supported: `main` only (pre-1.0).
Scope notes: write-capable tools do not exist yet; skills run read-only analyzers on text you pass in. Design and review evidence: `docs/SECURITY-REVIEW.md`, `docs/AI-SDLC.md`. Never install via `pip install netpaw` / `npx netpaw`.
